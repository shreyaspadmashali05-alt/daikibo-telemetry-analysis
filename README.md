# Daikibo: IoT Telemetry & Organizational Equity Analysis

An end-to-end data analysis project developed as part of a Deloitte simulation, focusing on translating raw industrial data into scalable business intelligence. This repository demonstrates a technical foundation in data parsing, advanced visualization, and equitable policy auditing to dictate a manufacturing organization's next strategic move.

## 🎯 Strategic Objectives
*   **IoT Telemetry Parsing:** Transformed unstructured factory telemetry data to track machine health, identify operational anomalies, and forecast predictive maintenance needs.
*   **Visual Pattern Recognition:** Engineered an interactive dashboard mapping temperature fluctuations across CNCs, LaserCutters, and SpotWelders to anticipate system failures.
*   **Pay Equity Audit:** Conducted a rigorous organizational data audit to ensure fair compensation practices, isolating discrepancies through structured data hygiene.

## 🛠️ Tech Stack & Methodology
*   **Data Transformation:** Microsoft Excel (Data modeling, structural cleaning, and advanced logic application)
*   **Visualization:** Tableau (Interactive dashboards and anomaly tracking)
*   **Business Intelligence:** Strategic reporting that translates raw numerical metrics into high-level IT and operational solutions.

## 📂 Repository Structure
*   `daikibo-telemetry-data.zip` — The raw, unstructured JSON logs containing IoT sensor output.
*   `Task 5 Equality Table.xlsx` — The initial raw organizational dataset for the compensation audit.
*   `Edited_Task 5 Equality Table.xlsx` — The cleaned, structured version demonstrating applied data integrity.
*   `Task 2_Dashboard.twbx` — The Tableau workbook showcasing predictive maintenance patterns.
*   `Task2_PDF.pdf` — A static export of the telemetry insights.
*   `Deloitte_Daikibo Telemetry & Pay Equity Audit.pdf` — The final executive presentation bridging the technical findings with corporate strategy.
